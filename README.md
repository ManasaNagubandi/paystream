# paystream
Enterprise-grade distributed payment processing system featuring microservices, Kafka event streaming, Redis idempotency, JWT authentication, and real-time transaction monitoring.

## Tech Stack

### Backend
- Java 17
- Spring Boot
- Kafka
- Redis
- PostgreSQL

### Frontend
- React
- Redux Toolkit

### DevOps
- Docker
- GitHub Actions

## Features
- Distributed payment processing
- Event-driven microservices architecture
- Kafka-based asynchronous communication
- JWT authentication and authorization
- Redis rate limiting and idempotency
- Real-time transaction monitoring dashboard
- CI/CD automation using GitHub Actions
